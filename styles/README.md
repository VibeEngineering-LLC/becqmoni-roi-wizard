# Контракт оформления ROI-мастера

Разметка и логика живут в `index.html`, оформление — здесь. Тема подключается так:

```html
<link rel="stylesheet" href="styles/host.css" id="themeCss">
```

Альтернативная тема кладётся файлом `styles/<имя>.css` и включается через
`index.html?style=<имя>` (значение запоминается в `localStorage.roiStyle`).
Тема-альтернатива **загружается поверх** `host.css`, поэтому может как переопределять
отдельные правила, так и полностью перекрывать оформление.

**Принятая тема проекта — `becqmoni.css`** (оформление под окно BecqMoni): она грузится
по умолчанию, без параметров. Голый `host.css` без темы — `index.html?style=none`.

## Что нельзя менять

- `id` любых элементов — по ним работает вся логика;
- структуру блоков и порядок узлов (JS создаёт и ищет строки внутри контейнеров);
- имена классов, перечисленных ниже, — их ставит и снимает JS;
- содержимое `data/*.js` — это данные, не оформление.

Всё остальное — цвета, шрифты, размеры, рамки, тени, отступы, порядок в потоке
через CSS — на усмотрение дизайна.

## Каркас

| Класс | Роль | Требования |
|---|---|---|
| `.app` | окно целиком | высота `100dvh`, документ не прокручивается |
| `.topbar` | заголовок окна | одна строка |
| `.tabs` / `.tabs button` / `.on` | закладки шагов | активная выделена; `b` внутри — счётчик |
| `.tabbody` / `.on` | тело шага | `display:flex` в состоянии `.on`, прокручивается только оно |
| `.statusbar` | строка состояния и кнопки шага | одна строка, не прокручивается |
| `.gbox` + `.lg` | group box с легендой | легенда «врезана» в рамку |
| `.gbox.grow` | group box, растягивающийся по высоте | |
| `.cols3`, `.cols2` | сетка шага 1 и фильтров шага 2 | |
| `.infoline` | полоса-подсказка под контролами | |
| `.presets` + `.preset` | строка готовых наборов в шаге 1 | полосы меню над закладками больше нет |

## Плотность

Целевая ширина панели в доке BecqMoni — 400–520 px, поэтому:
контролы высотой ~23 px, строка списка ~16–18 px, строка таблицы ~20–22 px,
подписи полей 12 px без капслока. Ничто не должно выходить за пределы контейнера
и вызывать горизонтальную прокрутку.

## Как проверить тему

1. `python -m http.server 8642` в корне проекта, открыть `index.html?style=<имя>`.
2. Пройти три шага: списки не пусты, таблица заполняется, статус меняется.
3. Проверить, что документ не прокручивается (`document.body.scrollHeight` = высота окна)
   и нет горизонтальной прокрутки ни на одном шаге.
4. Переключить RU/EN — подписи длиннее, вёрстка не должна ломаться.
