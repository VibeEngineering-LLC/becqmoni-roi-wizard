# Прототип интерфейса-панели (ветка `ui-panel`, 25.07.2026)

Ветка отвечает на разбор интерфейса. Разбор делится надвое, и это принципиально:

- **§ 0 — встраивание в BecqMoni.** Применение набора прямо в хост, ROI на живом спектре,
  R из FWHM-калибровки, нуклиды из «Обнаруженных пиков», итог по «Ошибка/SNR/FWHM».
  Всё это требует хоста и **в вебе не реализуемо** — это техзадание на C#-порт, его место
  в `SPEC.md` (фаза 4 плана). В вебе воспроизведена только *механика* — см. полосу спектра.
- **§ 1–4 — сама страница.** Вот это здесь и сделано.

## Что изменилось

**Каркас.** Документ больше не прокручивается: `100dvh`, слева панель 430 px, справа результат.
Шаги 1–4 стали вкладками, прокручивается только их содержимое и таблица линий. Это и есть
макет доковой панели: при ширине 400–520 px ничего не разъезжается (проверено — переполнения
контролов нет ни на одной вкладке, ни в RU, ни в EN).

**Полоса спектра над таблицей.** Набор рисуется на энергетической оси: штрих на каждую
выбранную линию, высота ∝ √I, цвет нуклида; в режиме зон — полупрозрачные окна ±k·FWHM/2,
так что перекрытия видно глазами. Наведение на строку таблицы подсвечивает штрих, наведение
на штрих показывает линию, клик по штриху снимает линию из набора. Это черновик той самой
двусторонней подсветки, которая в хосте будет работать с реальным спектром.

**Строка итога внизу.** «20 нуклидов · 98 линий · якорь Tl-208 (Th-232) 2614,5» плюс обе
кнопки экспорта — всегда на виду, а не на четвёртом экране.

**Пустой старт закрыт пресетами.** Пять готовых наборов одним кликом: ЕРН-фон (Th-232 + U-238
цепочками + K-40), поверка Cs-137/Co-60, ОСГИ, медицинские, ХРИ детектора и защиты. Пресет
сразу ставит порог 3 % — иначе в таблице сотни линий шума.

**Три списка → один.** Поиск / группы и ряды / ХРИ переключаются сегментным контролом над
единственным списком: колесо мыши работает предсказуемо, высота блока освободилась.

**Теория убрана из потока.** Разрешение, равновесие ряда, формат экспорта, источники данных —
под `«подробнее»`; в потоке осталась одна строка смысла («Sparrow: ближе 0,85·FWHM дублет
неразрешим — для маркеров сливаем»).

**Читаемость.** Капслок с подписей полей снят (13 px, обычный регистр); подписи кнопок
укорочены («+ семейство», «+ цепочка», «Дописать в библиотеку…»); в столбце «I отн.» —
микро-бар заливкой; периоды полураспада печатаются как 4,47·10⁹ лет вместо 4.47e+09;
десятичная запятая в русской локали; в тёмной теме поднят контраст выделения;
после скачивания — тост с путём и кнопкой «скопировать путь».

## Что из разбора сознательно не делалось

- **Всё из § 0** — работа хоста, не веба (см. выше).
- **Фильтры чипами** вместо галочек — переделка логики фильтрации; сейчас фильтры и так
  управляют выбором, а чипы дадут только читаемость состояния. Кандидат на следующий заход.
- **Бейджи типов как переключатели фильтра** — там же.
- **Мобильная вёрстка** — инструмент объявлен десктопным, специально ничего не делалось.
- **localStorage состояния и ссылка с состоянием** — состояние набора живёт в выгруженном
  файле; для панели в хосте это будет профиль BecqMoni.

## Как смотреть

```
cd <клон репозитория>
git checkout ui-panel
```
и открыть `index.html`. Вернуться к опубликованной версии — `git checkout main`.
Ветка не влияет на GitHub Pages: сайт собирается только с `main`.
